## 2. 架构变化（V0.1 → V0.2）

- **删掉**：Model Committee 作为线上架构（"双 ML 同向=相关误差放大"的结构缺陷）。
- **改定位**：Rule = benchmark；Interpretable = dev/验证工具；CatBoost/LightGBM = 单一 Production Predictive Model（只出预测量，不出 BUY/SELL）。
- **新增 8 步流水线**：Predictive Model → Agent Evidence Collection → **Evidence Time Gate** → Case Retrieval → Risk Gate → White-box Rule Engine → Human Confirmation → Post-trade Review。
- **硬约束**：Evidence 必须 `published_at ≤ decision_cutoff`（10:00）才能进决策；`decision_eligible` 程序计算、LLM 禁止判断；post-decision 只进复盘。

## 4. V0.2 相比 V0.1 的真实业务价值（最终回答）

> **不是"模型更准"。V0.2 的价值在风险护栏、可解释、可审计、防穿越——不在 PnL。**

| 问题 | V0.2 是否做到 | 证据 |
|---|---|---|
| 减少无意义交易 | ✅ | Risk Gate 移除 test −149,603 系统负期望交易；coverage 41%→5.8%（高选择性） |
| 减少极端亏损 | ✅ | maxDD −138k→−3k、worst −2,216→−208、CVaR −1,097→−198（但 V0.1 gate 已部分做到） |
| 识别何时不该交易 | ✅ | Evidence Time Gate（决策时点约束）+ reason_code（CONTROLX BUY / 低样本 / 低置信）明确 NO_TRADE 条件 |
| 解释为什么给建议 | ✅ | Decision Card + Rule Engine reason + Risk Gate reason，结构化、可复核（不再黑盒） |
| 交易员快速审查 | ✅ | `human_review_status`（PENDING/APPROVED/REJECTED/OVERRIDDEN）+ 证据/案例引用 |
| 事后复盘沉淀 | ✅ | Post-trade Review + Case Library + `UNFORESEEABLE_EVENT` 分类；亏损归因（MODEL_ERROR/MISSING_DATA/BAD_RULE/...），不默认"亏→调参" |

## 5. 诚实结论与局限

1. **V0.2 不提升 PnL**：Model+Gate −820（vs V0.1 +962），都输给漂移基准；盈利价值仍缺失（信号弱、CONTROLX SELL 在 v2 上负 EV）。
2. **gate 是护栏不是引擎**：它能拦掉 −149k 灾难，但保留集仍负（模型侧问题）；R6 低样本误伤 ELCA BUY（+731 正 EV 被关）。
3. **coverage 极低（5.8%）**：几乎只做安全节点/方向，代价是交易机会大幅缩减。
4. **仍缺**：真实 as-of weather forecast、本地燃气价、可再生能源出力、概率/尾部校准、Agent 信息检索接入（当前 evidence 全 UNCERTAIN）。
