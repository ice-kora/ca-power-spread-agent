Data Sources（数据来源）

MVP 数据来源说明 —— 不要让业务误以为"全是实时 CAISO API"。所有来源均为真实数据，as-of 约束由代码强制。
诚实

当前 MVP 的核心数据来自公司文件（已与 CAISO OASIS 对账验证）；实时 OASIS / GFS 采集处于接入状态或验证用途，尚未进入生产特征。GFS 预报作为 Agent Evidence 经统一 Collector 获取。

as-of 口径（P0-2 统一）

  • displayed available_at == Time Gate 判定口径（单一口径，防"展示 23:59、判定 00:00"的漂移）。
  • 无精确发布时刻的滞后/历史特征 → availability_basis=STRUCTURAL_LAG，available_at 显示为 ≤ decision_date 00:00 PT 的最晚可证上界，不编造精确时间戳。
  • 任何特征若 available_at > decision_cutoff 禁止进入训练/推理；UNKNOWN 未确认前默认禁用。
  • 数据文件详情见 docs/data_source_registry.md、docs/feature_availability_matrix.md、docs/company_data_audit.md、docs/weather_forecast_sources.md。

模型与规则

  • Model：V0.2（model_v2.py / predictions_v2.csv）—— 仅出预测量，test 窗口 2026-06-02 ~ 2026-08-05。
  • Risk Gate：code/risk_gate（PASS / WARNING / REJECT，11+ 规则）—— 守门员而非引擎。
  • Rule Engine：code/decision/rule_engine.py（R-A ~ R-I）→ BUY_DA / SELL_DA / NO_TRADE。
  • Evidence Time Gate：agent/evidence/time_gate.py（防穿越硬约束）。
  • Case Library：agent/case_library（337 条：auto 319 + manual 18，均带 case_available_at）。
